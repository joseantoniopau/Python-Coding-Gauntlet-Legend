The practice loop

A little guidance.
Then your own solution.

Begin with small expressions and guided encounters. Build toward complete functions, debugging, data structures and practical problem solving. The RPG gives you places to go; the work happens in Python.

  1. Read the situation

    Inspect the problem and its examples. Early encounters can ask you to choose an output, assemble code, or fill a small gap before you face a blank editor.

  2. Write, run, investigate

    Run real Python against tests. Use the feedback to find an edge case, repair an error, and try again. Lessons, hints and companions support practice when you need help.

  3. Return with less help

    Scaffolding fades as you progress. Memory shrines revisit patterns through variants, and harder encounters ask you to retrieve the approach yourself.

A small examplePYTHON

Count what is in the bag.

A dictionary turns repeated items into counts. An empty bag should produce an empty dictionary.

def count_loot(items):
    counts = {}
    for item in items:
        counts[item] = counts.get(item, 0) + 1
    return counts

A session you can finish

Choose a 10, 20 or 40 minute expedition. Steer toward review, a weak skill or fresh material, then pause and resume with your draft. Interview rehearsal offers a practice clock while sealed assessment keeps separate rules.

Keep the insight

Step through your Python on a public example, save a note in your grimoire, and revisit the approach in a changed boss rematch. Repository investigations add file diffs and room for a hypothesis, evidence and a regression check.

Regional architecture and quieter terrain give towns, paths and landmarks a clearer shape. Rebuilding changes a settlement's appearance as its state develops, from damaged structures to lit windows.

Scenes with a cast

Layered mountains, a vaulted index chamber and a village at dawn give the story a stage. The ending frames the people actually present in its script, holds its freeze frame, and returns to a quieter coda.

Practice & assessment

Help you can use.
Evidence you can trust.

A good practice session can include a hint. A sealed assessment asks a different question: what can you do without it?

During practice
Use guidance, inspect feedback, revisit ideas and experiment with a build. The game records the support used alongside your attempts.
During assessment
Sealed encounters and the timed practical restrict assistance. A new visual effect, item or companion cannot supply an answer or bypass that boundary.
After the result
Review the debrief and work on the failures. A story ending reflects its supplied result and cast; it does not award a better grade.
What it means
Progress describes performance in this game. It is not a guarantee of fluency, a hiring outcome, or a substitute for working with unfamiliar real projects.

REQUIRES PYTHON 3.11+ AND A BROWSER

macOS or Linux

With Python and Git installed, run these commands. The game has no pip install step.

git clone https://github.com/joseantoniopau/Python-Coding-Gauntlet-Legend.git
cd Python-Coding-Gauntlet-Legend
python3 run.py

On macOS, ./scripts/build_app.sh builds a double-clickable app from the checkout. Python is still required.

Windows or a ZIP download

Download the source ZIP and extract it. On Windows, double-click Play on Windows.bat, or run py -3 run.py from the extracted folder.
