Every game system is a learning mechanic

Freezing at a blank editor is a retrieval problem, not a knowledge problem. It is fixed by doing the thing repeatedly under mild pressure — which is what a good RPG already is. So nothing here is a wrapper around flashcards.

The game thingWhat it actually is
Enemy weaknessesThe problem's real edge cases. Probe correctly and you land a critical, because you found the case that breaks it.
Enemy resistancesIts performance ceiling. Brute force genuinely bounces off a resistant enemy.
Memory shrinesSpaced repetition over patterns, served as disguised variants so you can't pass by recognising the wording.
Chapter gatesEvidence you can do the earlier thing unaided. Not time spent, not problems seen.
HintsReal help at a real cost — they lower the rank you can earn, and they are refused outright in Interview Mode.
The last bossA timed practical with no hints, no probes, no pattern label and no companion.

It teaches the basics first

The most common way a learning game fails is opening at a difficulty that only helps people who didn't need it. The corpus is deliberately bottom-heavy, and every topic enters as a fill-in-the-blank before it is ever asked for cold.

Coverage spans the whole practical, not just algorithm puzzles: comprehensions, slicing and unpacking; the standard library you're expected to reach for; OOP and dunder methods; generators, decorators, closures and context managers; exceptions; linked lists, trees, graphs, DP, backtracking, greedy and bit manipulation — plus a family shaped like the real thing: here is an existing module, add a feature, fix a bug, keep its tests green.

Pick a class, then a build

Six classes, each a different way of solving problems rather than a different stat block — and every bonus attaches to a measured behaviour, so playing the class trains the habit it's named for.

ANALYST

Reasons before writing. Rewarded for correct probes and complexity calls, punished for guessing.

BERSERKER

Writes fast and iterates. Rewarded for speed, forgiving of failed attempts.

ARCHIVIST

Remembers. Strongest on spaced-repetition retests and pattern recognition.

WARDEN

Tests first. Rewarded for finding the edge case before submitting, not after.

ARTIFICER

Builds tools. Strongest on design and refactoring problems.

SEER

Reads code. Strongest on tracing, debugging and spot-the-flaw.

Three branches each, seven nodes per branch, with capstones that genuinely define a build. No node ever supplies an answer or skips a problem — they change how you engage, never whether you have to think.

Running your code is actually safe

Your solutions execute in a separate process behind four independent layers.

1 · SEATBELT

A sandbox-exec profile denies all network access and every write outside a scratch directory. macOS.

2 · RLIMITS

Hard ceilings on CPU seconds, address space, file size and process count.

3 · WALL CLOCK

The parent kills the whole process group for anything that survives the first two.

4 · PER-TEST

One runaway test times out on its own instead of taking the batch down with it.

On Windows, layers 1 and 2 do not exist — there is no seatbelt and no resource module. Isolation there rests on process separation and the wall-clock kill. The code you run is code you wrote, so the threat model is "my own infinite loop shouldn't wedge the machine" — but it is genuinely weaker than the macOS path, and you should know that rather than find out.

Download and play

You need Python 3.11 or newer and a browser. Nothing else — there is no pip install step, because there are no dependencies. It runs entirely on your machine: no accounts, no network, no telemetry.

macOS & LINUX

git clone https://github.com/joseantoniopau/Python-Coding-Gauntlet-Legend.git
cd Python-Coding-Gauntlet-Legend
python3 run.py

For a double-clickable app bundle, run ./scripts/build_app.sh.

WINDOWS

Download the ZIP from GitHub, unzip it,
then double-click:

    Play on Windows.bat

Or from a terminal: py -3 run.py. Installing Python? Tick "Add python.exe to PATH" in the installer.

Your save lives in ~/Library/Application Support/GauntletLegend on macOS, %APPDATA%\GauntletLegend on Windows, and ~/.local/share/gauntlet-legend on Linux.

All art and text are original and generated procedurally — there are no image assets in the repository. The soundtrack is six licence-clear tracks from Pixabay under the Pixabay Content License (nickpanek, alec_koff, Alex Morgan, myshoun), and the game synthesises its own music as a fallback if they are absent. Problems tagged as reported interview patterns are historically reported shapes, not guaranteed questions, and name no company.
